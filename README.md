# Data Analytics Tool

A modern neon-themed Data Analytics Tool developed using Python Flask, HTML, CSS, JavaScript, and Pandas. The application allows users to upload CSV files, analyze datasets, visualize insights through interactive charts, and explore data using a responsive and user-friendly interface.

## Features

* CSV file upload and processing
* Interactive data visualization charts
* Search and filter functionality
* Summary statistics generation
* Responsive dashboard layout
* Neon dark theme UI
* Smooth animations and interactive elements
* Dynamic analytics and insights display

## Technologies Used

* Python
* Flask
* Pandas
* NumPy
* HTML5
* CSS3
* JavaScript
* Chart.js

## Developed Using

* Antigravity AI Assistant
* Visual Studio Code / Antigravity IDE

## Prerequisites

Before running the project, install the following:

* Python 3.x
* Flask
* Pandas
* NumPy
* Matplotlib (optional)

Install required packages using:

```bash
pip install flask pandas numpy matplotlib
```

## How to Run

1. Open terminal inside the project folder.

2. Run the Flask application:

```bash
python app.py
```

or

```bash
py app.py
```

3. Open the browser and go to:

```text
http://127.0.0.1:5000
```

## Objective

The objective of this application is to provide an interactive platform for uploading, analyzing, filtering, and visualizing data efficiently through a modern and visually appealing analytics dashboard.
